# Vue 3 E-commerce App

A small e-commerce application built with Vue 3 using Composition API.

## Features
- Product listing
- Add/remove items from cart
- Cart total calculation
- Search and filtering
- Responsive UI

## Tech Stack
- Vue 3 (Composition API)
- TypeScript
- TailwindCSS
- REST API (mock)

## What I focused on
- Clean and scalable architecture
- Reusable components
- State management with composables
- Working with asynchronous data
